What I stand behind

I did not add "Approved by NCI". NCI has not approved this app, and saying it has would mislead the people Sam wants to trust it.

I did not add "Bank-grade security". This is a prototype with no security testing, so I can't promise that. Instead it stores nothing and moves no money.

HouseTab is a student prototype. All names, bills and amounts are invented. No payments are made and no data leaves this page.
